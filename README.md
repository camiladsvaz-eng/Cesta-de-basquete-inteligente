# Cesta-de-basquete-inteligente
O projeto consiste no desenvolvimento de uma mini cesta de basquete interativa, utilizando Arduino para controlar o funcionamento do jogo. A proposta é reproduzir, em escala reduzida, uma máquina de basquete do tipo arcade, na qual os participantes tentam acertar o maior número de arremessos dentro de um tempo determinado.
